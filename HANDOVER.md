# Release handover

Keep this concise: roughly 300 words or less. Link to tests or code where useful.

## Changed

What customer problems did you prioritize, and what changed?

## Verified

What did you run or reproduce? State outcomes, including failures and anything not tested.

## Remaining

What did you defer, and what would you investigate next?

## Release recommendation

Would you release this version to the pilot? With what limitations?

## AI use

Which tools did you use? Give one example where you checked, corrected, or deliberately accepted an agent's output. A full transcript is not required.

Final commit SHA: supply this to the interviewer after your final push (it need not be committed into this file).
